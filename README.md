# POL VPN

POL VPN is an Android rebrand of [Arman VPN v1.0.19](https://github.com/armanlife/arman-vpn-client/releases/tag/v1.0.19). It uses Arman's public source at [492dd7f](https://github.com/armanlife/arman-vpn-client/commit/492dd7f389c539790cde3d07167535d28788a0d0). The Android app uses POL branding and a separate package ID. Connection and sign-in code come from the public Arman source. Initial sign-in happens in POL.

- [POL source](https://github.com/Amir3M/POL/tree/codex/pol-arman-visual-fork)
- [POL releases](https://github.com/Amir3M/POL/releases)
- [Arman VPN source and documentation](https://github.com/armanlife/arman-vpn-client/tree/v1.0.19)
- [GNU General Public License v3](LICENSE)

Upstream authorship and history are preserved. POL is an independently branded distribution of the public build and is independent of Mozilla. Live service compatibility depends on the public build and is verified separately on a physical device.
